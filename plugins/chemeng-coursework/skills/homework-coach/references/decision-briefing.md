# 决策导航规则（Phase 0 / 0.5 / 4）

**这文件给谁看**：Mode A 做题时，AI 在动手算之前照这份规则先定档、生成决策简报、收决策、写决策日志。
**解决什么问题**：治"AI 替人把决策全做完，人看着它跑但什么都没学到"的病——AI 只铺地图，路人自己选；按你对这章的熟悉度分三档，0 基础也有入口。

---

## 第一步：先定档（每份作业开头问一次）

出简报前先问："这章内容你学到什么程度？"

| 档位 | 你说 | 流程差别 |
|---|---|---|
| **学习模式**（0 基础） | "没学过这章" | 每个决策点前 AI 先讲 3-5 句概念（带出处，**讲概念不讲答案**），再照练习模式提问 |
| **练习模式**（有基础，默认） | "学过但不太熟" / 不表态 | 两段式：判别条件先不给，你试答后 AI 才揭示对答案 |
| **冲刺模式**（熟练 / 赶 due） | "很熟" / "赶时间" | 完整简报（带适用条件列）快速确认；"直接算" = AI 代选 |

- 同一份作业跨章节可以中途换档（如 Q1 是学过的章、Q2 没学过）
- 档位记进 decisions.md 表头

## 决策简报模板（Phase 0，每道题一份；下面是练习模式默认版）

```markdown
### Q1 决策简报

**已知**：F = 100 kg/h（进料）、x_F = 0.30（题面参数全列，带单位）
**待求**：需要几个理论级 N
**参数缺口**：要到 N，得先定 → 操作线两端点 → 先算 S/F 和终端组成（倒推链）

**课内工具箱**（只列名字和出处，判别条件你试答后才揭示）：
| 候选方法 | 出处 |
|---|---|
| 闭式公式 R=w/W | L02 知识块3 |
| 变夹带图解（七步法） | L02 知识块4 |

**课外资源**：平衡数据 → manifest 里 Appendices.pdf（未跑 MinerU，要手查）；密度 → NIST
**轮到你**：你觉得哪个能用？依据是什么？（说不上来就回"展开"）
```

要点：
- **不算任何数值**，连"显然是图解法"这种暗示都不给
- **练习/学习模式的工具箱不带"适用条件 / 什么时候不能用"列**——那正是要你自己提取的判别知识，直接列出来就变成表面配对了。**冲刺模式才加回这两列**
- 每道题一份；一份 tutorial 多道题就逐题出（可以一次消息里连出几份，决策收集也逐题过）
- 简报直接发对话里，同时存底进 `task.md`

## 知识来源降级链（"课内工具箱"和"判别条件"从哪来）

按顺序查，**绝不凭训练数据印象编课内方法**：

1. **`_principles.md` 存在**（Glob `01_Projects/<CODE>_*/_principles.md`）：
   - 公式引用用 `(X.Y)` 编号
   - 判别条件直接抄 §末的"常见错…判别：…"blockquote 和选用准则表（grep `判别` / `常见错` / `选用`）
2. **没有 `_principles`**（如 CME214）：
   - 出处用 lecture 知识块锚点 `[[L##_xxx#知识块 N — 标题]]`
   - 候选池参考 `index.md` 对应章的"本周关键概念"列表，再 Read 相关 L## 确认判别条件
3. **物性 / 外部数据**：Read `manifest.md` References 段，"什么时候翻它"列就是现成的映射；有 `✅ MinerU 索引` 的可直接 grep（做法同 ingest-tutorial Step 1.6）
4. **课内都没有**：WebSearch / WebFetch，简报里标注 URL 来源 + "课外"字样

## 决策点怎么列（Phase 0.5 过哪些）

**方法级**（必过）：
- 这是什么题型？（如：恒定夹带还是变夹带？错流还是逆流？）
- 用哪套公式 / 图解法？

**假设级**（必过，有几个过几个）：
- 关键物理假设：完全混合？稳态？限制剂是谁？驱动力用分压还是浓度？
- 边界 / 终止条件：算到什么纯度停？取哪端数据？
- 参数来源：题面给的 / 你假设的 / 查笔记的 / 查外部的

怎么从题面找决策点——现有解答里决策稳定表现为三种句式，反着用即可：
1. **条件排除式**（"夹带随浓度变 → 闭式不适用"）→ 变成"方法选择"决策点
2. **假设声明句**（"假设完全混合 ⟹ tie line 过 B 顶点"）→ 变成"假设采纳"决策点
3. **数据来源标注**（"数据来自题目 / 请核实"）→ 变成"参数来源"决策点

**不属于决策点**（AI 自动，别问）：画图样式、排版格式、代码组织、量纲换算。

## 交互协议（Phase 0.5，两段式）

每个决策点走这个循环：

1. **你先试答**：选哪个 + 依据是什么（简报结尾那句就是第一问）
2. **AI 才揭示判别条件对答案**（从降级链查来的"适用条件 / 什么时候不能用"这时才亮出来）：
   - 答对且依据站得住 → 记 `[自主]`，下一个决策点
   - 答错 / 依据有漏洞 → 指出漏洞在哪（"这个方法要求夹带恒定，但题面 r 在变"），**不直接给正确答案**，让你重选；重选对了记 `[提示后]`
3. **你说"不知道 / 展开"** → AskUserQuestion 放选项：
   - 每个选项 = 候选方法，description 写"适用条件 + 出处"，**不加(推荐)标记**
   - 多个假设级决策可合并成一次 AskUserQuestion（最多 4 问）
   - 选完记 `[提示后]`
4. 全部决策拍板 → 才进 Phase 1 写 calc.py

## 学习模式（0 基础）：边做边教

流程和练习模式一样，只多一个"先教"环节：

- **每个决策点前**，AI 先用 3-5 句大白话讲清这个决策涉及的概念（是什么、为什么存在、物理图像），带出处锚点（`[[L01_xxx#知识块 11 — 标题]]` 或 `(X.Y)`）
- **护栏：讲概念不讲答案**——可以讲"错流是每级都加新鲜溶剂、逆流是溶剂和料液反着走"，不能说"所以这题该选逆流图解"。判别仍留给你试答
- 讲完照常两段式：你试答 → AI 揭示判别条件对答案
- 一题做完，把这题用到的知识块列成**补读清单**写进 decisions.md，事后花 10-15 分钟补读成体系

## 冲刺模式（熟练 / 赶 due）

- 简报用完整版：工具箱加回"适用条件 / 什么时候不能用"两列，你扫一眼直接确认走法（或 AskUserQuestion 菜单式直接选）
- 你说"直接算" → 提醒一句"这次跳过决策环节"，AI 自己选方法，decisions.md 里全标 `[AI代选]`
- `[AI代选]` 的比例 = 你欠的学习债，复盘小结时点一句

## decisions.md 模板（Phase 4）

```markdown
# 决策日志 — {作业slug}（YYYY-MM-DD，档位：练习模式）

| # | 决策点 | 你的选择 | 自主/提示后 | 依据出处 |
|---|---|---|---|---|
| 1 | 方法：闭式 vs 变夹带图解 | 变夹带图解 | 自主 | L02 知识块4 |
| 2 | 假设：完全混合 | 采纳 | 提示后 | L02 知识块4 平衡关系 |
| 3 | 参数：终端夹带取 r=0.30 | 取夹带线低浓度端 | 提示后 | 题面数据表 |

## 卡住的知识点（复习优先）
- [ ] 变夹带 vs 恒定夹带的判别条件 → L02 知识块4

## 补读清单（学习模式才有）
- [ ] L02 知识块3 — 闭式公式 R=w/W（约 5 分钟）
- [ ] L02 知识块4 — 变夹带图解七步法（约 10 分钟）
```

规则：
- `[提示后]` 的决策点自动进"卡住的知识点"清单，指向具体笔记锚点
- 同一份作业多道题共用一份 decisions.md，编号连续；中途换过档就在表头写清（如"Q1-2 练习 / Q3 学习"）
- 写完在对话里口头小结："这次 N 个决策你自主拿下 X 个，卡在 …（对应笔记 …）"

---

## 三句话总结

1. **这文件说了什么**：做题前先问你这章学到什么程度分三档——没学过就边做边教、学过就先试答再对判别条件、很熟就完整简报快速确认——全部决策你拍板后 AI 才动手算，做完留决策日志。
2. **我什么时候回来看**：想确认 AI 为什么这么问我、或想调档位规则（嫌教得太多 / 问得太烦）的时候。
3. **看完能做什么**：知道开头报哪个档、"展开"和"直接算"分别会发生什么、decisions.md 里 `[自主]` / `[提示后]` / `[AI代选]` 是怎么来的。
