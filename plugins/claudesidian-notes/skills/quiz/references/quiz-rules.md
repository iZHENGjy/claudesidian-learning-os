# 出题规则

## 零提示（最重要）

只有真懂的人才能答对。

1. **选项描述不暴露对错**
   - 差：选项"质量平均速度 v"，描述"流体力学中使用的那个速度，所以是正确答案"
   - 好：选项"质量平均速度 v"，描述"按质量分数加权"
2. **不给任何选项加"推荐"**
3. **正确选项位置随机**，不总在第一个或最后一个
4. **题干问行为、用途、结果**，不在题干里点名答案
   - 差："Fick 定律的负号表示扩散从浓到稀吗？"
   - 好："Fick 定律里的负号说明了什么？"
5. **干扰项是本学科真实存在的概念或常见误解**，不编明显荒谬的选项

## 题型

1. **事实回忆**：定义、公式、单位、适用条件
2. **概念理解**：为什么要这样定义 / 这样做
3. **结果预测**：换一个条件会怎样（"管长加倍，通量怎么变？"）
4. **区分对比**：两个容易混的概念差在哪
5. **找错**：给一段错误推导或错误结果，问错在哪一步（用"误区与陷阱"里的真实错误）

## 难度配比

- 摸底：易 40% · 中 40% · 难 20%
- 补弱：中 30% · 难 70%
- 难题复习：各难度均匀

## 补弱时考 🔴 概念

- **不重复**上次的原题，换情境考同一个知识
- 例：上次把 v 和 V 混了 → 这次给一组新的组分和速度，问"质量扩散速度要减哪个平均速度、结果是多少"

## 计算类选择题

- 数字用复习库 `verify.py` 验算过的结果，或当场写一行 Python 算出来再出题
- 干扰项用真实会犯的错误算出来（如单位没换、g/kg 混用、减错平均速度），不随便编数

## 复述题判分

1. 先定 3–4 个关键环节（取讲义"用自己的话说"里的清单），每个环节只有"有 / 没有"
2. 逐个环节判：有 / 缺 / 错
3. 说得流畅但缺一个环节 = 没过
4. 只补缺的那个环节，不重讲整节

## 格式

- 每轮 4 道选择题，每题 4 个选项，单选
- 标题 "Q1. 主题"（≤ 12 字）
- 题目和反馈用用户的语言
