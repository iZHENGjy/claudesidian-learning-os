# Skill: build-review-vault

## Role

讲义笔记（`L##`）是为**第一次学懂**写的，长、讲得细。期末复习要的是另一种东西：一页看完的公式、集中的易错点、能反复刷的题。本 skill 把一门课**已有**的笔记压成这样一个复习库，配合 `quiz` skill 出题考你、记录掌握度。

**只整理，不新增**：复习库里的每一条内容都必须能追溯到本课已有的 L## / T## / `_principles.md`，不引入笔记里没有的新知识。

## When to trigger

- "做 CMEXXX 的复习库" / "期末复习资料" / "给这门课出题库" / "build review vault"
- `ingest-lecture` 报告末尾提示过、用户点头

不应触发：单节课整理（→ ingest-lecture）/ 解题（→ ingest-tutorial）/ 想直接被考（→ quiz，若复习库已存在）

## Inputs / Outputs

- **In**：课程代码（缺则问一次）；`01_Projects/<CODE>_课名/` 下的 `L*.md`、`T*.md`、`_principles.md`（可选）、`index.md`
- **Out**：

```
01_Projects/<CODE>_课名/复习库/
├── 00-总览.md        主题地图 + 题库清单 + 掌握度看板 + 薄弱点
├── 01-公式速查.md     必背公式一页纸（有 _principles.md 时以它为准）
├── 02-易错点.md       全课误区合集，每条折叠、链回出处
├── 题库/<主题>.md     每个主题 ≥ 10 题，答案折叠
├── 掌握度/            由 quiz skill 创建和更新（本 skill 只建空目录）
└── verify.py         题库里所有计算题答案的验算
```

## Workflow

### Step 1: 盘点材料

1. Glob `L*.md`、`T*.md`，Read `index.md`、`_principles.md`（若有）
2. 列出每讲的部分（`## 第 N 部分`）和知识点小节（`### x.y`）。旧格式笔记（知识块）也能用，按 `## 知识块` 拆
3. **划分主题**：按内容而不是按周，把相关知识点合成 3–8 个主题（一个主题约 3–6 个知识点）。主题名用中文短语，如"浓度与速度""Fick 定律与总通量"
4. 把主题划分表给用户看一眼（主题 → 来自哪几讲哪几节），确认后继续

**已有复习库时**：只为新增的讲次补主题和题目，**不覆盖 `掌握度/`**，不重写用户改过的题。

### Step 2: 公式速查（`01-公式速查.md`）

- 有 `_principles.md`：按主题列出必背公式，**沿用它的 (X.Y) 编号**，每个主题标题后链接 `→ [[_principles#…]]`
- 没有：从各讲"课件里的概念"段收集公式，每条后链回出处小节 `→ [[L##_…#x.y …]]`，并在开头提示"建议先跑 distill-principles"
- 每个公式一行：公式 · 一句话含义 · 适用条件。只放公式和条件，不放推导
- 最后一段"考前必背 5 条"

### Step 3: 易错点（`02-易错点.md`）

来源（按优先级）：各讲"误区与陷阱"块 → T## 的"易错"段 → `_principles` 反向校验报告里的 bug。每条写成：

```markdown
> [!danger]- 易错：（错误说法，一句话）
> - **错在哪**：（一句）
> - **正确做法**：（一句，含数字或公式）
> - 出处：[[L02_…#误区与陷阱]]
```

按主题分组。只收笔记里**真实出现过**的误区，不编。

### Step 4: 题库（`题库/<主题>.md`）

每个主题一个文件，**≥ 10 题**，题型配比：**记忆 ≥ 60%、应用 ≥ 20%、分析 ≥ 2 题**（10 题即 6/2/2）。模板和出题规则 → `references/templates.md`。要点：

- 每题标题带题型 `[记忆]` / `[应用]` / `[分析]` 和所考概念
- 答案一律 `> [!answer]- 看答案` 折叠
- 应用题用课件例题或 T## 题目的数据改编，答案写清公式 → 代数 → 结果（带单位）
- 分析题考"为什么 / 两个概念的区别 / 换一个条件会怎样"，优先从"误区与陷阱"和"暂停"的预测题改编
- 每题末尾一行 `考点：[[L##_…#x.y …]]`，quiz 靠它把题目归到概念

### Step 5: 验算

所有应用题的数字写进 `复习库/verify.py`，每个答案一条 `assert`：

```bash
python "01_Projects/<CODE>_课名/复习库/verify.py"
```

不过 → 改题目答案，不许改断言凑数。

### Step 6: 总览（`00-总览.md`）

按 `references/templates.md` 的总览模板：主题地图（主题 → 来源讲次 → 题库链接 → 题数）、学习工具链接、掌握度看板（初始全部 ⬜ 未测）、薄弱点（初始为空，由 quiz 填）。

### Step 7: 自检 + 报告

自检：每个主题有题库且 ≥ 10 题、题型配比达标、每题有"考点"链接、`verify.py` 通过、所有 `[[链接]]` 指向已存在的笔记或标题。

```markdown
## 复习库完成: <CODE>

**主题**: N 个（列名）
**公式速查**: N 条（来源: _principles / 各讲）
**易错点**: N 条
**题库**: 共 N 题（记忆 a / 应用 b / 分析 c），verify.py 通过
**下一步**: 说"考我 <CODE>"开始测验（quiz skill）
```

## Rules

1. **只整理不新增** — 每条内容都能追溯到本课已有笔记
2. **答案永远折叠** — 主动回忆才有效
3. **每个计算答案都验算**
4. **不覆盖掌握度** — 那是用户的学习记录
5. **只链接已存在的笔记和标题**
