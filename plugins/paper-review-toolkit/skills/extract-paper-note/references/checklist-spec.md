**给人复查用** —— 论文里每张图/每个表，讲清它是什么、数据进没进主 Excel、进在哪。
打开主 Excel 对着 checklist 就能逐条核对，不用回头翻论文。

## 类型分类（固定 6 类）

- **数据图** — 有具体数值，能读出数字进表（应力应变、电导、模量曲线）
- **趋势图** — 只有定性趋势/形状，无精确值（log-log 主曲线、示意趋势）
- **机理图** — 结构/示意/相图，解释为什么（self-assembly 示意、相分离图）
- **配方/合成图** — 合成路线、Scheme（进配方列/卡片）
- **表征QC图** — NMR/SEC/UV-Vis/XRD 等纯鉴定，通常不入表（只佐证某字段）
- **数据表** — 表格形式的数值（Table S1 之类）

一张图可标两类（如 "数据图+趋势"）。

## "入 Excel?" 三态

- **✓** — 数据进了主 Excel，"位置"列写清 sheet + 列 + 行
- **部分** — 部分进了（如主列没放但 notes/卡片提了），"位置"列说明去向
- **✗** — 没进（QC 图、定性图），"位置"列写 `—` + 一句为什么

## "位置"列写法

格式：`sheet名! 列名 @ 行号`
- `样本数据! Tensile Strength (MPa) @ r109,r111`
- `论文清单! Monomer, Initiator`
- `样本卡片! A12`（卡片写 var_code 即可）
- 没进就 `—`

## 结尾：覆盖率自评（3-4 行）

```
- 数据图 N 张全部入表 / 趋势图 M 张（K 张进了主列，其余进 notes）
- 表征QC图 P 张未入表（合成鉴定，不是性能数据）
- 主 Excel 性能列覆盖：电导/拉伸/伸长/韧性 共 X 个数值 × Y 个样本行
- 配方覆盖：论文清单 4 列 + 样本卡片 Z 个变量
```

## 规则

1. **不要 emoji** — ✓/✗/— 用这三个符号即可
2. **每张图都要列**（main + SI 全列，包括没入表的 QC 图）—— 漏列 = 复查时不知道这图查过没
3. **位置要精确到行**（样本数据写 r106-115 这种）—— 用户对着 Excel 行号核对
4. **讲解 ≤ 2 行** —— 不重复 main.md 的完整 alt，只浓缩"这图核心结论"
5. 行数 = main 图数 + SI 图数 + 表数（结尾自评对一下数）
