## 气体扩散系数 → [[L03_diffusion_coefficient_estimation#3.1 Hirschfelder 方程与碰撞积分（Hirschfelder equation & collision integral）（p.18–21）]]

| 公式 | 含义 | 条件 |
|---|---|---|
| $D_{AB} = 0.001858\,T^{3/2}(1/M_A + 1/M_B)^{1/2}/(P\sigma_{AB}^2\Omega_D)$ | Hirschfelder | 非极性；cm²/s、atm、Å、g/mol |
| $D_2 = D_1\,(P_1/P_2)(T_2/T_1)^{3/2}\,\Omega_{D,1}/\Omega_{D,2}$ | 温度压力换算 | — |
| $D_{AB} = 10^{-3}T^{1.75}(1/M_A + 1/M_B)^{1/2}/\{P[(\Sigma v)_A^{1/3} + (\Sigma v)_B^{1/3}]^2\}$ | Fuller | 无 LJ 参数 |
| $\Omega_D = \Omega_{D0} + 0.196\,\delta_{AB}^2/T^*$，$\sigma_{AB} = (\sigma_A\sigma_B)^{1/2}$ | Brokaw | 极性气体 |
| $D_{1\text{-mix}} = 1/\sum(y_n'/D_{1\text{-}n})$，$y_n' = y_n/(1 - y_1)$ | Wilke | 多组分 |

## 液体扩散系数 → [[L04_liquid_solid_pore_diffusivity#知识块 4 — Wilke-Chang 方程(液相主力公式)]]

| 公式 | 含义 | 条件 |
|---|---|---|
| $D_{AB} = k_BT/(6\pi r\mu_B)$ | Stokes–Einstein | 大分子、球形 |
| $D_{AB} = 7.4\times10^{-8}T(\Phi_BM_B)^{1/2}/(V_A^{0.6}\mu_B)$ | Wilke–Chang | 稀溶液；cm²/s、cP、cm³/mol |
| $D_{AB} = 13.26\times10^{-5}\mu_B^{-1.14}V_A^{-0.589}$ | Hayduk–Laudie | 水 |
| $D_{AB} = KT/(\mu_BV_A^{1/3})$ | Scheibel | 无 $\Phi_B$ |
| $D_{AB}\mu = (D^o_{AB}\mu_B)^{x_B}(D^o_{BA}\mu_A)^{x_A}$ | Leffler–Cullinan | 浓溶液 |
| $D_{T_1}/D_{T_2} = [(T_c - T_2)/(T_c - T_1)]^n$ | Tyn | 温度外推 |
| $D_{AB} = 2RT/[(1/\lambda_+^0 + 1/\lambda_-^0)F^2]$ | Nernst | 稀电解质 |

## 固体与多孔介质 → [[L04_liquid_solid_pore_diffusivity#知识块 14 — 多孔扩散(2):Effective diffusivity 总公式]]

## 考前必背 5 条

1. $\mathbf N_A = -cD_{AB}\nabla y_A + y_A(\mathbf N_A + \mathbf N_B)$
2. Hirschfelder 方程（记住单位：cm²/s、atm、Å、g/mol）
3. Wilke–Chang 方程（黏度用 cP）
4. $D_{KA} = 4850\,d_{pore}\sqrt{T/M_A}$ 与 $1/D_{Ae} = 1/D_{AB} + 1/D_{KA}$
5. $D = D_0e^{-Q/RT}$
